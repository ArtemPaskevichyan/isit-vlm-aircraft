# Военный или гражданский самолёт: сравнение двух VLM

Учебный проект: бинарная классификация летательных аппаратов по фотографии
двумя vision-language моделями Google через Gemini API.

**Итоговый отчёт:** [`results/report.md`](results/report.md) — методика, 25 кейсов
с превью, метрики, confusion matrix и разбор ошибок.

## Модели

| Ключ | Модель | Класс |
|---|---|---|
| `gemini_flash` | `gemini-3.6-flash` | старшая Flash-модель, сильные рассуждения |
| `gemini_lite` | `gemini-3.5-flash-lite` | облегчённая и быстрая |

Обе модели доступны по одному API-ключу Google через OpenAI-совместимый
эндпоинт `https://generativelanguage.googleapis.com/v1beta/openai`, поэтому
сравнение не смешивает различия моделей с различиями инфраструктуры.
Интерес сравнения — в разнице «весовых категорий»: видно, сколько понимания
контекста добавляет старшая модель на задаче, где класс определяется не только
силуэтом, но и ливреей, регистрацией и ролью борта.

Обе модели получают одинаковый промпт, `temperature=0`, `max_tokens=120`,
изображение 1024 px по длинной стороне. Ответ — JSON с полями
`class`, `confidence`, `reason`.

## Датасет

25 изображений с Wikimedia Commons: 13 военных, 12 гражданских, 19 «ловушек».

| Тип | Смысл |
|---|---|
| `E` | простой эталонный случай |
| `T1` | военная платформа с гражданским обликом (P-8, KC-46, KC-135, E-3) |
| `T2` | военный транспорт с силуэтом лайнера (C-17, Il-76, An-124) |
| `T3` | VIP/государственный борт (VC-25) |
| `T4` | специальная/пожарная авиация (CL-415, Be-200, C-130 Coulson) |
| `T5` | один тип в двух ролях (Mi-8, Il-76) |
| `T6` | БПЛА (MQ-9) |
| `T7` | гражданский борт в камуфляже (L-39, An-2, Yak-52) |
| `T8` | гражданский тип на военной службе (King Air 350 / C-12) |

- `data/labels.csv` — разметка, тип ловушки, обоснование, автор и лицензия.
- `data/images/{ID}.jpg` — мастер-копия 1400 px.
- `data/images/{ID}_model.jpg` — то, что отправляется модели (1024 px, q85).
- `data/contact_sheet.jpg` — контактный лист для быстрой проверки.

Правила разметки зафиксированы до прогона: `military` — борт вооружённых сил
или созданный для боевых/боево-обеспечивающих задач; `civilian` — авиакомпании,
частные, грузовые, пожарные, санитарные, полицейские борта.

## Быстрый старт

```bash
python3 -m venv .venv
.venv/bin/pip install pandas pillow requests

# ключ: создаётся в Google AI Studio (aistudio.google.com -> Get API key)
echo 'GEMINI_API_KEY=...' > .env
```

Бесплатный тариф не требует карты, но имеет лимиты: у `gemini-3.6-flash`
это 20 запросов в сутки на проект, у `gemini-3.5-flash-lite` — заметно больше.
При упоре в лимит скрипт повторит запрос с паузой, а при исчерпании суточной
квоты прогон можно продолжить позже — успешные ответы закэшированы. Если нужно
добить остаток сегодня, можно создать второй ключ в новом проекте
и передать его так: `--key-env GEMINI_API_KEY_2`.

Пилот на 3 фото (6 запросов):

```bash
.venv/bin/python tools/run_eval.py --pilot
```

Полный прогон (50 запросов):

```bash
.venv/bin/python tools/run_eval.py --all
```

Отчёт:

```bash
.venv/bin/python tools/make_report.py
# -> results/report.md (самодостаточный файл, превью вшиты в base64)
```

## Артефакты прогона

| Файл | Что внутри |
|---|---|
| `results/raw.jsonl` | каждый запрос: модель, ответ, latency, токены, статус, кэш-ключ |
| `results/predictions.csv` | плоская таблица для анализа |
| `results/report.md` | итоговый отчёт: методика, 25 кейсов, метрики, анализ ошибок |

Повторный запуск не тратит квоту: ответы кэшируются по ключу
`sha256(модель + промпт + хэш изображения)`. Ошибочные HTTP-запросы в кэш не попадают.
Флаг `--refresh` игнорирует кэш.

Модели и эндпоинт задаются в словаре `MODELS` в `tools/run_eval.py` (поля
`model`, `base_url`, `key_env`), поэтому замена модели или провайдера — это
правка одной строки в конфиге.

## Структура

```
data/                  датасет и разметка
results/               сырые ответы, предсказания, отчёт
tools/
  dataset_plan.json    план выборки: объект, класс, ловушка
  commons_search.py    поиск кандидатов на Wikimedia Commons
  selection.json       утверждённые файлы
  build_dataset.py     скачивание, ресайз, labels.csv, хэши
  run_eval.py          запросы к моделям, кэш, predictions.csv
  progress.py          статус прогона: сколько запросов собрано, чего не хватает
  make_report.py       сборка report.md с метриками
```

## Ограничения

- 25 изображений, разметка одним человеком, намеренный перекос в сложные случаи.
- `confidence` модели — самооценка, не калиброванная вероятность.
- Latency включает сеть и очередь на стороне сервиса.
- Бесплатный тариф имеет суточные лимиты; версии моделей у провайдера могут меняться,
  поэтому прогон привязан к дате.
